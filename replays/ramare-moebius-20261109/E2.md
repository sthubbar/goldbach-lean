## The ε0 definition (printed p.342, (7.1))

Paper: "Let X = √((log x)/R) where R = 9.6459 08801, and let ε0(x) = √(8/17π) X^{1/2} e^{−X}."
Lean: `X x = Real.sqrt (Real.log x / 9.645908801)`, `epsilon0 x = Real.sqrt (8 / (17 * Real.pi)) * Real.sqrt (X x) * Real.exp (-X x)`.
Verdict: MATCH. R has the same digits. √X equals X^{1/2} because X ≥ 0. All targets have x ≥ 1, so log x ≥ 0 and Real.sqrt's truncation never applies.

## RH-height hypothesis

- The paper states Theorems 7* and 11 unconditionally. Their proofs use the finite RH verification from Rosser–Schoenfeld 1975 (paper [11]) through the height A. On p.342, (7.6) assumes "A ≤ T2" and deduces "X ≥ log(A/17) > 11.62". With A = 1894438.5122, log(A/17) = 11.6212 (computed here), which fits the paper's "> 11.62".
- The paper does not print A's numerical value. grep of the OCR finds no 1894, 1.89 or 3,502. That A = 1894438.5122 rests on RS75 and on E.md's computation F(A) ≈ 3502500, not on this paper.
- The Lean adds FiniteRH 1894438.5122 as an explicit premise. Against an unconditional printed theorem, an extra premise can only weaken the Lean statement. It is also exactly the computational input the paper uses, so in substance the statements match. Neither reading makes the Lean stronger.
- I did not check RS75 for whether the paper's input also included simplicity of the zeros. FiniteRH asserts only re ρ = 1/2. If the input did include simplicity, the Lean premise is weaker than the paper's input, which makes the Lean conclusion harder to prove, not stronger.

## Overall verdict

No Lean Schoenfeld 1976 statement is stronger than the printed paper or the corrected paper. All 8 targets and ε0 match the page images in constants, strict versus non-strict relations and endpoints. (7.4) matches the corrigendum's corrected form exactly. The only difference is the explicit FiniteRH(1894438.5122) premise (and PsiCert in the Cond comparator), which makes the Lean weaker or equal.
